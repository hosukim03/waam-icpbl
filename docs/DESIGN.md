# 멀티로봇 WAAM 경로계획 알고리즘 설계 (IC-PBL 1단계)

## 0. 문제

목표 형상(STL)을 로봇 3대가 협업 적층한다. 출력은 `trajectory.csv`
(robot_id, time_s, x_mm, y_mm, z_mm, mode∈{T,D,W}).

**제약(위반 시 FAIL)**
- XY Reach: 베이스에서 TCP까지 XY 거리 ≤ 1500mm
- 충돌: 두 로봇의 (베이스→TCP) 선분 간 거리 ≥ 250mm, TCP 간 거리 > 200mm
- 형상: 전체 IoU ≥ 0.90, 층별 IoU ≥ 0.80, Coverage ≥ 0.80,
  Overfill ≤ 0.30, 실패층 비율 ≤ 5%
- 속도: 적층 8mm/s ±10%, 이동 ≤ 150mm/s
- 형식: 로봇별 첫 행 time_s=0.0, 마지막 행 mode=W

**목적** makespan 최소화 → 계산시간 최소화 → 일반화

## 1. 설계 원칙 (파라미터에서 유도)

| 원칙 | 근거 |
|---|---|
| **P1. 경로를 잘게 쪼개지 않는다** | 아크 on/off 각 1초 = 세그먼트당 2초 고정비. 8mm/s 기준 16mm어치 |
| **P2. 섹터 분할로 충돌을 구조적으로 회피** | 팔 = 베이스→TCP 긴 선분. 중심 수렴 구조상 근접 작업 불가 |
| **P3. 이동은 현재 층 바로 위로 낮게** | 이동 고도 규정 없음. z=1000 왕복은 13.3s/회로 과도 |
| **P4. 층 배리어(bottom-up 동기화)** | 물리적 타당성 + 층 내 동일 z → 충돌 판정이 순수 2D로 단순화 |
| **P5. 얇은 벽은 1패스, 넓은 면은 윤곽+인필** | 비드 8mm. 벽 두께 ≤ 12mm면 중심선 한 줄로 IoU 확보 |

### 섹터 분할의 기하학적 근거

로봇 베이스는 원점에서 1400mm, 120° 간격. 각 로봇에 자기 베이스 방향
중심의 120° 섹터를 할당하면:

- **리치**: 섹터 최원점(반경 700, 각도 ±60°)까지 거리 1212mm ≤ 1500mm → 자동 충족
- **충돌**: 두 로봇이 인접 섹터에서 중심으로부터 r 이상 떨어져 작업하면
  팔 간 거리 ≈ 1.732·r. r ≥ 145mm 이면 250mm 확보

→ **중심 반경 145mm 원은 배타 구역**으로 두고 한 번에 한 로봇만 진입.
→ 섹터 경계에도 완충 각도를 둔다(초기값 ±5°).

## 2. 파이프라인

```
STL → [S1 슬라이싱] → [S2 경로생성] → [S3 배정] → [S4 순서]
    → [S5 시각부여+충돌해소] → trajectory.csv
```

### S1. 슬라이싱
- 층 중심 z_k = build_plane_z + (k − 0.5)·layer_height = 1.0, 3.0, 5.0, …
- 각 z_k에서 STL 단면 폴리곤 추출 (trimesh `section`)
- 검증기가 층 중심 z에서 자르므로 동일 기준을 쓴다

### S2. 경로 생성 (IoU의 관문)
층 단면 폴리곤 A에 대해:
1. **윤곽 경로**: A를 안쪽으로 bead_width/2 = 4mm 오프셋한 선 (shapely `buffer(-4)`)
2. **잔여 영역** R = A ⊖ (윤곽 비드 커버 영역)
3. R이 비면 종료 (얇은 벽 → 1패스)
4. 아니면 **인필**: 간격 s = bead_width − overlap (초기값 7mm)로 지그재그
   - 인필 방향은 층마다 90° 회전 (구조 + 균형)
5. 폴리라인 목록 P 반환. **연속 경로는 끊지 않는다 (P1)**

**튜닝 노브**: 오프셋량, 인필 간격 s, 인필 각도.
IoU 미달이면 s를 줄이고(겹침↑), Overfill 초과면 s를 늘린다.

### S3. 로봇 배정
1. 각 폴리라인의 대표 각도 θ와 중심거리 r 계산
2. **1차: 섹터 배정** — θ가 속한 섹터의 로봇에 할당
3. **예외 처리**
   - r < 145mm (중심 배타구역) → `EXCLUSIVE` 표시, 직렬 처리 대기열로
   - 섹터 경계 완충대에 걸침 → 폴리라인을 경계에서 분할하거나 EXCLUSIVE
   - 리치 위반 → 도달 가능한 로봇 중 부하 최소에 재배정
4. **2차: 부하 균등화** — 층별 로봇 부하 L[r] 계산 후,
   겹침 가능 폴리라인에 대해 move/swap 국소탐색
   - 단, 재배정 시 **P1 위반(분할) 금지**. 통째로 옮기는 것만 허용

### S4. 순서 최적화
로봇별 폴리라인 집합에 대해:
- 최근접 이웃으로 초기 순서 → **2-opt** 개선
- 비용 = 이동 거리 (끝점→다음 시작점). 폴리라인은 양방향 진입 가능하므로
  방향 선택도 함께 최적화 (2-opt with orientation flip)

### S5. 시각 부여 및 충돌 해소
층 k에 대해 로봇별로 독립 시간표 생성:

```
현재시각 t ← 층 시작시각
각 폴리라인 p (순서대로):
    T 구간: 현재 위치 → p 시작점 (z = 층 z + 10mm 로 올라갔다 내려옴)
    W 구간: 1.0초  (arc on)
    D 구간: p를 따라 8mm/s로 적층 (곡선은 chord 오차 ≤ 0.1mm로 분할)
    W 구간: 1.0초  (arc off)
```

그 후 **충돌 해소**:
1. 시간축을 0.05초 간격으로 이산화
2. 로봇 쌍마다 (베이스→TCP) 선분 거리와 TCP 거리 검사
3. 위반 구간 발견 시 **우선순위가 낮은 로봇에 W 삽입**하여 뒤로 밀기
4. 위반이 없을 때까지 반복 (우선순위: 남은 작업량이 많은 로봇이 높음)

**층 배리어**: 모든 로봇이 층 k를 끝낸 뒤 층 k+1 시작.
먼저 끝난 로봇은 자기 홈 근처에서 W.

**중심 배타구역**: EXCLUSIVE 폴리라인은 층 내에서 직렬 배치.
한 로봇이 처리하는 동안 다른 로봇은 자기 섹터 바깥쪽 작업을 하거나 대기.

### S6. 출력
- 로봇별 첫 행 time_s = 0.0 (홈 위치, mode W)
- 마지막 행 mode = W (파킹, 다른 로봇 동선 방해 없는 위치)
- robot_id 오름차순, 그 안에서 time_s 오름차순 정렬

## 3. 단계적 구현 계획

| 단계 | 내용 | 목표 |
|---|---|---|
| **V0** | 로봇 1대만 사용, 전체 직렬 | **PASS 확보**. 기하 파이프라인(S1·S2) 검증 |
| **V1** | 섹터 3분할 + 층 배리어, 배정은 섹터만 | 충돌 없이 3배 병렬 |
| **V2** | 부하 균등화(S3-2) + 순서 최적화(S4) | makespan 개선 |
| **V3** | GA/SA로 배정+순서 동시 탐색 | 상대평가 경쟁력 |
| **V4** | (선택) RL로 배정 정책 학습 | 2차 발표용 |

**V0가 최우선.** IoU 90%를 통과하는 S2를 확보하지 못하면 이후 단계가 전부 무의미하다.

## 4. 미확인 사항 (구현 전 확인 필요)

1. 층 간 시간 선후(bottom-up)를 검증기가 실제로 검사하는가 — 미검사로 보이나
   물리적 타당성을 위해 배리어 유지 권장
2. `simulation.max_tcp_step_mm: 5.0`이 입력 waypoint 간격 제약인지,
   검증기 내부 리샘플링 해상도인지
3. ARM_ENVELOPE 판정식에서 arm_clearance가 실제로 더해지는지
   (required=250 vs margin 계산식 불일치) — 소스 확인 필요
4. 예제 `examples/sample_job`의 trajectory.csv 실물 확인
