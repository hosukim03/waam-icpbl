# WAAM IC-PBL 용어집

앞의 용어를 알아야 뒤의 용어가 이해되는 순서로 정리함.

## 1. 장비와 공정
- **WAAM (Wire Arc Additive Manufacturing)**: 금속 와이어를 전기 아크로 녹여 한 층씩 쌓는 금속 3D 프린팅
- **아크 (arc)**: 용접할 때 생기는 전기 불꽃. 켜고 끄는 데 각 1초
- **비드 (bead)**: 녹았다 굳은 금속 줄 한 가닥. 폭 8mm, 높이 2mm
- **토치 (torch)**: 로봇 팔 끝의 용접 노즐
- **TCP (Tool Center Point)**: 토치 맨 끝점. trajectory.csv의 x·y·z가 이 점의 좌표
- **베이스 (base)**: 로봇이 바닥에 고정된 자리
- **리치 (reach)**: 베이스에서 TCP가 닿는 최대 수평거리. 1500mm
- **홈 (home)**: 로봇 기본 대기 위치. 베이스에서 400mm, 높이 1000mm
- **작업공간 (workspace)**: 형상이 놓이는 원형 영역. 반경 700mm

## 2. 형상 데이터
- **STL**: 3D 형상을 삼각형 수천 개로 표현한 파일 형식
- **메시 (mesh)**: 그 삼각형들의 그물망
- **watertight**: 메시가 구멍 없이 완전히 닫힌 상태
- **슬라이싱 (slicing)**: 3D 형상을 일정 높이마다 수평으로 자르기
- **층 (layer)**: 썰어낸 한 장. 두께 2mm
- **단면 (cross-section)**: 그 높이에서 자른 면의 모양. 그 층에서 채울 영역

## 3. 경로
- **경로 / 툴패스 (toolpath)**: TCP가 지나갈 선
- **윤곽 (contour)**: 단면 테두리를 따라 도는 경로
- **오프셋 (offset)**: 선을 평행이동. 테두리에서 4mm(비드 폭 절반) 안쪽으로
- **인필 (infill)**: 윤곽 안쪽을 채우는 경로(보통 지그재그)
- **인필 간격**: 인필 선 사이 거리. 7mm로 1mm씩 겹치게
- **폴리라인 (polyline)**: 짧은 직선을 이은 꺾은선
- **세그먼트 (segment)**: 경로 조각 하나. 아크 한 번 켜고 끄는 단위
- **chord 오차**: 곡선을 직선 조각으로 근사할 때의 어긋남

## 4. 시간표와 출력
- **궤적 (trajectory)**: 시간에 따른 TCP 위치 기록. 제출물
- **waypoint**: 궤적의 한 줄. 시각 + 좌표 + 모드
- **모드**: D(용접하며 이동) / T(용접 없이 이동) / W(제자리 대기)
- **makespan**: 세 로봇 중 가장 늦게 끝나는 시각. 최소화 목표
- **파킹 (parking)**: 먼저 끝난 로봇의 대기 위치. 다른 로봇 방해 금지

## 5. 판정
- **타깃 (target)**: 만들어야 할 목표 단면
- **적층 영역**: 실제 깐 비드가 덮는 영역
- **교집합 / 합집합**: 둘이 겹친 부분 / 둘을 합친 전체
- **Coverage** = 교집합 ÷ 타깃 (≥ 80%)
- **Underfill**: 목표인데 못 채운 비율
- **Overfill**: 목표 밖으로 넘친 비율 (≤ 30%)
- **IoU** = 교집합 ÷ 합집합 (전체 ≥ 90%, 층별 ≥ 80%). 빠짐과 넘침을 둘 다 벌함. 항상 Coverage 이하
- **캡슐 (capsule)**: 선분을 일정 반경으로 부풀린 알약 모양. 로봇 팔 근사
- **ARM_ENVELOPE**: 팔 캡슐끼리 충돌 판정 (중심선 간 250mm 필요)
- **TCP_RADIUS**: 토치 끝끼리 충돌 판정 (200mm 초과 필요)
- **clearance**: 추가로 떨어져야 하는 여유 거리. 팔끼리 50mm

## 6. 알고리즘 용어
- **섹터 (sector)**: 작업공간을 120도씩 나눈 부채꼴. 로봇별 담당
- **배정 (assignment)**: 어떤 경로를 어느 로봇이 맡을지 결정
- **셋업 (setup)**: 작업마다 붙는 준비시간. 아크 2초(순서 독립) / 이동(순서 의존)
- **배칭 (batching)**: 셋업을 줄이려 작업을 묶기 = 경로 안 쪼개기
- **부하 (load)**: 한 로봇이 맡은 일의 총 시간
- **2-opt**: 두 구간을 뒤집어 꼬인 순서를 푸는 개선 기법
- **층 배리어 (layer barrier)**: 모든 로봇이 한 층을 끝내야 다음 층 시작
- **배타구역**: 중심 반경 145mm. 한 번에 한 로봇만
